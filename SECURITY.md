# Security Policy

## Reporting a Vulnerability

Report vulnerabilities through a [GitHub private security advisory](https://github.com/seunghyeon1004/claude-code-skillsets/security/advisories/new).

Do not open a public issue, discussion, or pull request for a suspected
vulnerability. Include a clear reproduction, affected paths or versions, impact,
and any suggested mitigation. Do not include credentials, tokens, private user
data, or other secrets in the report.

## Scope

Security reports may cover repository code, manifests, generated marketplace
artifacts, installed plugin instructions, dependency declarations, and the
release workflow. External skills remain in their upstream marketplaces; report
upstream code vulnerabilities to their maintainers as well.

We will acknowledge the report privately, assess reproducibility and impact,
and coordinate a fix before public disclosure where appropriate.
