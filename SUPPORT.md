# Support / 지원

## English

### Public Support

Use [GitHub Issues](https://github.com/seunghyeon1004/claude-code-skillsets/issues)
for reproducible bugs, documentation problems, installation failures, and
feature proposals about this project's broker, manifests, packaged skills,
runtime, or local state format.

Include the operating system, Claude Code and Node.js versions, plugin name and
version, exact reproduction steps, expected result, and a minimized diagnostic
result. Do not include a credential, token, secret, account identifier, private
prompt, environment value, unredacted absolute executable path, executable hash,
or unredacted user data. For Claude identity failures, report the normalized
version and whether path, realpath, hash, or version validation failed.

### Security Reports

Do not report a suspected vulnerability in a public issue. Use
[GitHub private vulnerability reporting](https://github.com/seunghyeon1004/claude-code-skillsets/security/advisories/new)
and include affected versions, reproducible impact, and a safe reproduction
without live secrets.

### Support Boundary

This project can investigate its own decision broker, package metadata,
consent and approval boundaries, local state handling, and generated runtime.
For the behavior, account, authentication, billing, network, privacy, or service
availability of an external plugin, contact that upstream plugin or provider.
An external marketplace listing does not transfer upstream support ownership to
this project.

Local-record deletion and external-provider boundaries are documented in
[PRIVACY.md](PRIVACY.md).

## 한국어

### 공개 지원

이 프로젝트의 broker, manifest, 패키지 스킬, runtime 또는 로컬 상태 형식에 관한
재현 가능한 버그, 문서 문제, 설치 실패 및 기능 제안은
[GitHub Issues](https://github.com/seunghyeon1004/claude-code-skillsets/issues)에
등록하세요.

운영체제, Claude Code와 Node.js 버전, 플러그인 이름과 버전, 정확한 재현 단계,
기대 결과 및 최소화한 진단 결과를 포함하세요. 자격 증명, 토큰, 비밀 값, 계정 식별자,
비공개 prompt, 환경 변수 값, 삭제하지 않은 실행 파일 절대경로·hash 또는 사용자
데이터를 넣지 마세요. Claude 신원 오류는 정규화한 버전과 path, realpath, hash,
version 중 어느 검증이 실패했는지만 보고하세요.

### 보안 신고

의심되는 취약점을 공개 이슈에 등록하지 마세요.
[GitHub 비공개 취약점 신고](https://github.com/seunghyeon1004/claude-code-skillsets/security/advisories/new)를
사용하고, 실제 비밀 값을 제외한 영향 버전, 재현 가능한 영향 및 안전한 재현 절차를
포함하세요.

### 지원 범위

이 프로젝트는 자체 decision broker, 패키지 메타데이터, 동의·승인 경계, 로컬 상태
처리 및 생성 runtime을 조사할 수 있습니다. 외부 플러그인의 동작, 계정, 인증, 결제,
네트워크, 개인정보 또는 서비스 가용성 문제는 해당 upstream 플러그인이나 공급자에게
문의하세요. 외부 마켓플레이스 등재가 upstream 지원 책임을 이 프로젝트로 이전하지는
않습니다.

로컬 기록 삭제와 외부 공급자 경계는 [PRIVACY.md](PRIVACY.md)에 설명되어 있습니다.
