# Shared Core Support / 공용 코어 지원

## English

Use [GitHub Issues](https://github.com/seunghyeon1004/claude-code-skillsets/issues)
for a reproducible Shared Core packaging, loading, namespacing, documentation,
or skill-instruction problem. Include the operating system, Claude Code version,
`shared-core` version, invoked skill name, reproduction steps, and expected and
actual behavior. Do not include a credential, token, secret, private prompt, or
unredacted user data.

Do not put a suspected vulnerability in a public issue. Use
[GitHub private vulnerability reporting](https://github.com/seunghyeon1004/claude-code-skillsets/security/advisories/new).

Shared Core has no installer or external service. If a problem occurs in a tool,
external plugin, or provider that the user separately selected while applying a
Shared Core workflow, report that behavior to the relevant upstream project or
provider. See this package's [PRIVACY.md](PRIVACY.md) for data boundaries.

## 한국어

공용 코어의 패키징, 로딩, 이름공간, 문서 또는 스킬 지침 문제를 재현할 수 있다면
[GitHub Issues](https://github.com/seunghyeon1004/claude-code-skillsets/issues)를
사용하세요. 운영체제, Claude Code 버전, `shared-core` 버전, 실행한 스킬 이름,
재현 단계, 기대 동작과 실제 동작을 포함하세요. 자격 증명, 토큰, 비밀 값, 비공개
prompt 또는 삭제하지 않은 사용자 데이터를 넣지 마세요.

의심되는 취약점을 공개 이슈에 올리지 말고
[GitHub 비공개 취약점 신고](https://github.com/seunghyeon1004/claude-code-skillsets/security/advisories/new)를
사용하세요.

공용 코어에는 설치 프로그램이나 외부 서비스가 없습니다. 사용자가 공용 코어 워크플로를
적용하면서 별도로 선택한 도구, 외부 플러그인 또는 공급자에서 문제가 발생했다면 해당
upstream 프로젝트나 공급자에게 신고하세요. 데이터 경계는 이 패키지의
[PRIVACY.md](PRIVACY.md)를 확인하세요.
